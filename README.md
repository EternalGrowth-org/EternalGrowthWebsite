# EternalGrowth Tutoring Website

A playful, Bauhaus-inspired website for your Long Island tutoring organization, combining clean geometric design with fun, engaging content inspired by modern brands like Graza.

## 🎨 Design Features

### Bauhaus Elements
- **Clean geometric shapes** - Animated circles, triangles, and squares throughout the site
- **Bold primary colors** - Red (#E31E24), Blue (#0047AB), Yellow (#FFD700), and Black (#1A1A1A)
- **Functional typography** - Inter font family with strong weight variations
- **Minimal decoration** - Focus on form and function
- **Grid-based layouts** - Structured, organized content presentation

### Playful Elements (Graza-inspired)
- **Casual, friendly language** - Product names like "Spark," "Focus," "Connect," "Flex"
- **Enthusiastic tone** - Exclamation marks and engaging descriptions
- **Fun facts section** - Educational trivia to keep things interesting
- **Interactive elements** - Hover effects, animations, and click interactions
- **Bright, engaging visuals** - Colorful cards and animated shapes

## 🚀 Features

### Navigation
- **Fixed header** with smooth scrolling navigation
- **Mobile-responsive** hamburger menu
- **Dynamic background** that appears on scroll

### Sections
1. **Hero Section** - Introduces "Spark" with animated geometric shapes
2. **Three Ways to Learn** - Focus, Connect, Flex learning methods

### Interactive Elements
- **Animated shapes** that respond to hover and click
- **Form validation** with custom notifications
- **Smooth scrolling** between sections
- **Parallax effects** on geometric shapes
- **Entrance animations** for cards and sections
- **Easter egg** - Try the Konami code! (↑↑↓↓←→←→BA)

### Responsive Design
- **Mobile-first approach** with tablet and desktop optimizations
- **Flexible grid layouts** that adapt to screen sizes
- **Touch-friendly buttons** and navigation
- **Optimized typography** scaling with viewport

## 📱 How to Use

### Running the Website
1. **Local Development**: Simply open `index.html` in your web browser
2. **Live Server** (recommended): Use VS Code's Live Server extension or any local server
3. **Deployment**: Upload files to any web hosting service

### Customization
- **Colors**: Modify CSS variables in `:root` section of `style.css`
- **Content**: Update text in `index.html`
- **Contact info**: Change phone, email, and address in the contact section
- **Subjects/Pricing**: Modify the subject cards in the services section

### Contact Form
- Currently set up with client-side validation
- Shows success/error notifications
- **To make it functional**: Replace the form submission simulation in `script.js` with your actual form handling service (like Netlify Forms, Formspree, or a custom backend)
